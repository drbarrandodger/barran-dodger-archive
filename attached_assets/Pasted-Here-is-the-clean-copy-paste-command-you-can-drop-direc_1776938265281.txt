- Store document metadata in /src/data/documents.json

- "/" (Homepage)

- Header.jsx (navigation menu)
- Footer.jsx

- SearchBar.jsx

Create /src/data/documents.json with this format:

    "type": "PDF",
    "category": "Legal",
    "description": "Short neutral description",

    "tags": ["evidence"]
  }
