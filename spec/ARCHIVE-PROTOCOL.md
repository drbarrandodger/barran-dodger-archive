# Archive protocol

## Preservation boundary

The repository is the archive's source of truth. Presentation shells, cards, indices, and routes are secondary layers.

## Protocol rules

- never delete or rename original documentary artefacts as part of presentation work
- preserve original repository-relative paths in every derived layer
- keep internal inventory and public publication scopes separate
- load public collection summaries before record-level inventory in the catalogue shell
- publish only what is intentionally included in the Pages build output
- treat metadata-only and public-metadata-sensitive records as review boundaries, not invitations to broaden publication automatically
