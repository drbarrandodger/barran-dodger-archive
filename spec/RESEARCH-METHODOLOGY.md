# Research methodology

## Evidence-first workflow

1. preserve the source artefact
2. capture its original path and repository context
3. distinguish source description from analytical interpretation
4. note unresolved questions explicitly rather than filling gaps
5. seek corroboration before upgrading material to stronger status classes

## Citation discipline

- cite the original repository path first
- avoid invented references or synthetic corroboration
- mark unavailable, unverified, disputed, or partial material explicitly

## Phase 1 limitation

No broad forensic synthesis is performed in this phase. Research architecture is defined here so later phases can operate without altering the source record layer.
